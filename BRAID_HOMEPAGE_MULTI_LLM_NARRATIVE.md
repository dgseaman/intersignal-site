# Braid homepage narrative refresh

## Primary homepage message

> More than one LLM should not mean starting over every time.

A second model may live on another computer, specialize in another task, or operate in another physical location. Without a shared state layer, useful context often dies where it was created or has to be copied manually. Braid gives selected context a portable, inspectable form, then lets the receiving system retrieve what matters for a new question while keeping acceptance and local use under its control.

## Why this framing leads

The homepage now begins with the everyday problem rather than a specific benchmark:

- people increasingly use several AI systems;
- those systems often live on different devices, serve different roles, or operate in different places;
- each new model or session usually begins without the situational context created elsewhere;
- manual copy-and-paste moves text, but does not itself provide durable provenance, receiver-owned acceptance, relevance retrieval, or conflict preservation.

## General-audience proof language

The controlled tests are presented as evidence of a wider capability:

- a receiving machine gained project-specific context it did not have before;
- it later answered a differently worded question in a fresh inference call;
- it selected relevant material and left unrelated material out of the reconstructed context;
- it kept conflicting values and their sources visible;
- when the local answer model still made a mistake, the separation between evidence and generated output made that mistake inspectable.

The main reading path no longer requires visitors to understand a specific test name, object digest, vector threshold, atom count, or byte count before understanding the product thesis. Exact records remain available in the research and readiness sections.

## Inclusive use cases now emphasized

- moving work from laptop to workstation or edge device;
- allowing research, review, writing, and specialist models to work from accepted shared context;
- continuing across people, rooms, offices, and physical sites;
- preserving useful state after a session ends or a machine goes offline;
- keeping human and receiver authority separate from transport and model output.

## Current claim boundary

Braid is presented as an active shared-state layer for selected, inspectable context. The page does not claim transfer of model weights, hidden activations, KV cache, a complete mind, or infallible reasoning. Braid can preserve and surface evidence; the receiving model can still misunderstand it.

## Release status language

Braid 1.7.0a3 is described as the current Semantic Field Proof Build candidate. The page states that frozen macOS, Linux, Windows, restart, replay, and varied-hardware validation remains the immediate promotion gate. No public stable-release claim has been added.
