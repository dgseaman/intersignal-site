# Archangel 1.8 - short physical acceptance checklist

This is a test plan, not a completed test record. Preserve a6 and back up the complete actual profile. Keep private keys private.

1. Quit a6/a6-c1 and launch the complete 1.8 ZIP on the real Mac/Linux targets. Verify version 1.8.0, unchanged fingerprints, preserved notes/channels and the pre-1.8 desktop/trust snapshot. Never run two versions on the same live profile.
2. With the old saved delta still present, Share summary must open blank. X and Escape must dismiss it. Drafts must explicitly restore the old delta. Discard must leave the failed Sent entry and accepted objects intact. Test new-message after a successful send as well.
3. Send a new harmless exact note in each direction, inspect Accepted & indexed, and ask a fresh receiver-field question. Keep the source's subject/time scope in view. A plausible answer alone is not the full receipt/query evidence.
4. Test a permitted Channel Chat question, inspect Using N shared notes, test permission optout/revocation and channel isolation. Ordinary Messenger notes are not automatically channel members.
5. Restart and repeat retrieval. Deliberately test uncertain/partial outcomes only with harmless notes; successful and uncertain recipients must remain locked. No automatic retries.
6. Execute native Windows launch/ACL/shutdown separately; Mac/Linux success does not qualify Windows. Physical QR and actually configured overlay/WAN remain separate cases.
7. Download the exact public ZIP in a signed-out private browser, verify its checksum, and repeat a clean install using the shipping launchers. Record interpreter, OS, embedding/completion digests and exact errors.

Retain the full raw receipt/query evidence when available. The September 7 screenshots are predecessor evidence and do not replace these version-specific steps. a7 Resilience remains a separate optional member preview.
