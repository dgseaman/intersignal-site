# Start Braid Archangel 1.9.4

Quit the previous Braid version before using an existing profile.

- **Mac (Apple silicon, macOS 13+):** extract the ZIP, copy Braid.app to Applications,
  and open it. It contains its own runtime and opens a browser without Terminal.
  The app is ad-hoc signed, not notarized; macOS may require your explicit opening
  approval through Privacy & Security. Do not change global security settings.
- **Windows:** extract everything, then double-click Start Braid.cmd. Standard
  CPython 3.10–3.13 with pip/venv is required. Keep all files together.
- **Linux:** extract everything and run `sh "Start Braid.sh"` from that folder.
  Standard CPython 3.10–3.13 with pip/venv is required. File-manager script handling
  varies. Keep all files together.

Windows/Linux first setup installs pinned dependencies into a private runtime.
Read docs/OFFLINE.md to prepare an offline pack. No system Python packages change.

Choose **Try a sample conversation** for a harmless first success without Ollama
or another computer. Edit/exclude a passage, open Compose to choose a layout, then
Review & export. Check Phone and Print previews, approve the exact edition, and
export its local ZIP. Nothing is uploaded. Extract the full publication ZIP and
open index.html; images are stored in its assets folder.

For real private context sharing, return to Braid, prepare your local model route,
exchange public rig cards, and approve the fingerprints on both computers. Import
the same Channel card and select approved publishers before using notes in Chat.
Inspect each handoff's four-step receipt. See CHANNELS_GUIDE.md in the source bundle
and the retained guides in docs/. Optional paid WAN access is configured separately.

Read RELEASE_NOTES.md, MIGRATION_NOTES.md, and TEST_RESULTS.md before testing.
